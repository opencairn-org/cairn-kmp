# Test font

`OpenSans-Regular.ttf` is Open Sans 1.10 (Ascender Corporation / Google), licensed under the
[Apache License, Version 2.0](https://www.apache.org/licenses/LICENSE-2.0).

It is used by the screenshot tests only, so that text renders the same on every machine: the
platform's default font differs between a developer's desktop and the CI runner. The app itself
ships no font and uses the system one.
